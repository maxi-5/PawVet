# Tablero (GitHub Projects)

Columnas: **Backlog → Por hacer → En progreso → En revisión → Hecho**.

| Regla | Detalle |
| --- | --- |
| Tarjeta | Una por ítem del backlog (B-xx) o tarea técnica; título con el ID y responsable asignado |
| Por hacer | Ítems comprometidos en la planificación del sprint |
| En progreso | Máximo 2 tarjetas por persona |
| En revisión | Hay un pull request abierto enlazado a la tarjeta |
| Hecho | PR aprobado por el otro integrante e integrado a `main`, con pruebas en verde |

Capturas: al inicio y al cierre de cada sprint en `evidencia/` (`sprint-N-inicio.png`, `sprint-N-cierre.png`).
